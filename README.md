# hopecard.ca scene plates

Image assets for the hopecard.ca homepage scroll scenes. The Vercel build for
`hope-card-landing` downloads these files by pinned commit and checks their SHA-256
before serving them from hopecard.ca. Do not edit files in place; add new files
and update the pinned commit in `scripts/fetch-plates.mjs` instead.

- `downtown-towers.webp`: photo by Geoffrey Faber on Unsplash (Unsplash License).
- All other plates are AI renders of Hamilton, Ontario.
